# AudioPlayer - Асинхронне відтворення з пам'яті

## Дата: 2 жовтня 2025

## Фінальна архітектура

### Рішення: Багатопотоковість + Кешування

Поєднання найкращого з обох підходів:
- ✅ **Кешування в пам'яті** - всі файли завантажуються один раз при ініціалізації
- ✅ **Асинхронне відтворення** - через окремі потоки (threading)
- ✅ **Швидке відтворення** - немає затримок на читання з диска
- ✅ **Не блокує UI** - звук грає в фоновому потоці

## Як це працює

### 1. Ініціалізація
```python
player = AudioPlayer(sounds_dir)
# Всі WAV файли завантажуються в self.cache: dict[str, bytes]
```

### 2. Відтворення
```python
player.play("sound.wav")
# 1. Перевіряємо наявність у кеші
# 2. Створюємо daemon-потік
# 3. У потоці викликаємо winsound.PlaySound() з SND_MEMORY (синхронно)
# 4. Основний потік одразу продовжує роботу (асинхронно)
```

### 3. Внутрішня реалізація
```python
def _play_sync(self, audio_data: bytes) -> None:
    """Відтворює звук СИНХРОННО в окремому потоці"""
    winsound.PlaySound(audio_data, winsound.SND_MEMORY | winsound.SND_NODEFAULT)

def play(self, filename: str) -> None:
    """Запускає відтворення АСИНХРОННО через потік"""
    audio_data = self.cache[filename]
    thread = threading.Thread(
        target=self._play_sync, 
        args=(audio_data,), 
        daemon=True  # Автоматично завершується при виході з програми
    )
    thread.start()  # Не чекаємо завершення потоку!
```

## Переваги фінального рішення

### ✅ Швидкість
- Файли в пам'яті - **миттєве відтворення**
- Немає затримок на I/O операції

### ✅ Асинхронність
- UI не блокується під час відтворення
- Потоки daemon - не потрібно очищення

### ✅ Надійність
- Помилки відтворення не падають програму
- Чіткі винятки при ініціалізації

### ✅ Зручність використання
```python
# Просто викликаємо - решту робить плеєр
player.play("sound.wav")
# Одразу можна продовжувати роботу!
```

## Порівняння підходів

| Критерій | File-based | Memory-based<br/>+ Threading |
|----------|------------|------------------------------|
| Швидкість | Повільніше (I/O) | ⚡ Швидко |
| Асинхронність | ✅ Так (SND_ASYNC) | ✅ Так (thread) |
| Використання пам'яті | Мінімальне | Більше (кеш) |
| Складність коду | Проста | Середня |
| **Для нашого випадку** | Підходить | ✅ **Оптимально** |

## Технічні деталі

### winsound обмеження
- `SND_MEMORY | SND_ASYNC` - ❌ **НЕ працює** (помилка Windows)
- `SND_MEMORY` (sync) - ✅ Працює, але блокує
- `SND_FILENAME | SND_ASYNC` - ✅ Працює, але повільно

### Наше рішення
- `SND_MEMORY` (sync) **У ПОТОЦІ** - ✅ Ідеально!

### Daemon потоки
```python
thread = threading.Thread(..., daemon=True)
```
- Автоматично завершуються при виході з програми
- Не потрібно явно зупиняти
- Ідеально для звуків

## Використання

```python
from pathlib import Path
from simple_otp.ui.audio_player import AudioPlayer

# Ініціалізація (завантаження в пам'ять)
sounds_dir = Path(__file__).parent / "sounds"
player = AudioPlayer(sounds_dir)

# Відтворення (асинхронно з пам'яті)
player.play("notification.wav")

# Перевірка кешу
print(f"Loaded: {player.get_available_files()}")
print(f"Cache size: {player.get_cache_size()} bytes")

# Перезавантаження (якщо файли змінилися)
player.reload()

# Зупинка всіх звуків
player.stop()
```
