## Вступ

Simple OTP — це безпечна десктопна програма для генерації одноразових паролів на основі часу (TOTP). Вона дозволяє керувати всіма вашими обліковими записами двофакторної автентифікації в одному місці.

### Основні можливості:

- Генерація TOTP-кодів згідно зі стандартом RFC 6238
- Шифрування файлів паролем для захисту ваших секретів
- Підтримка кількох файлів облікових записів
- Швидкий пошук облікових записів
- Копіювання кодів у буфер обміну
- Звукові сповіщення для користувачів скрінрідерів
- Повна підтримка клавіатурної навігації
- Багатомовний інтерфейс (українська, англійська)

## Чому?

Я, автор програми, незрячий і шукав простий та доступний додаток для Windows, який би генерував TOTP-коди та був повністю сумісний зі скрінрідерами.

Спільнота порадила лише один широко доступний варіант — **KeePass**. Хоча KeePass здатен зберігати й генерувати TOTP, він не містив деяких функцій, які були важливі саме для мого робочого процесу та потреб у доступності.

Маючи трохи вільного часу та багато натхнення, я вирішив створити Simple OTP. Мета — зробити простий, чіткий та зручний інструмент, орієнтований на користувачів, що покладаються на скрінрідери та клавіатурну навігацію.

Якщо ви маєте ідеї або потреби, пов'язані з доступністю, буду радий отримати ваші відгуки — вони допоможуть зробити програму кращою для всіх.

## Початок роботи

### Перший запуск

При першому запуску Simple OTP ви побачите порожнє вікно програми. Щоб почати користуватися програмою, вам потрібно:

1. Створити новий файл облікових записів (`Ctrl+N`)
2. Встановити пароль для захисту ваших даних
3. Додати перший обліковий запис (`F7`)

### Системні вимоги

- Windows 10 або новіша версія

## Робота з файлами

### Створення нового файлу

Щоб створити новий файл облікових записів:

1. Виберіть **Файл → Створити...** або натисніть `Ctrl+N`
2. Виберіть місце збереження та введіть ім'я файлу
3. Встановіть надійний пароль
4. Підтвердьте пароль

> **Важливо:** Зберігайте ваш пароль у безпечному місці. Якщо ви забудете пароль, відновити доступ до файлу буде неможливо!

### Відкриття існуючого файлу

Щоб відкрити існуючий файл:

1. Виберіть **Файл → Відкрити...** або натисніть `Ctrl+O`
2. Виберіть файл з розширенням `.json`
3. Введіть пароль для розшифрування файлу

### Нещодавні файли

Програма зберігає список нещодавніх файлів для швидкого доступу. Ви можете:

- Відкрити нещодавній файл через меню **Файл → Нещодавні файли**
- Очистити історію через **Файл → Нещодавні файли → Очистити історію**

## Управління обліковими записами

### Додавання облікового запису

Щоб додати новий обліковий запис:

1. Натисніть `F7` або виберіть **Обліковий запис → Додати**
2. Заповніть обов'язкові поля:
   - **Назва:** ідентифікатор облікового запису (наприклад, user@example.com)
   - **Секрет:** ключ Base32 від постачальника (наприклад, JBSWY3DPEHPK3PXP)
3. За бажанням заповніть додаткові поля:
   - **Постачальник:** назва сервісу (Google, GitHub тощо)
   - **Кількість цифр:** зазвичай 6 (за замовчуванням)
   - **Алгоритм хешування:** зазвичай SHA1 (за замовчуванням)
   - **Інтервал:** зазвичай 30 секунд (за замовчуванням)
4. Натисніть **Додати**

### Де знайти секретний ключ

При налаштуванні двофакторної автентифікації більшість сервісів показують QR-код і текстовий ключ. Цей текстовий ключ (зазвичай 16-32 символи) і є секретом Base32, який потрібно ввести в Simple OTP.

### Видалення облікового запису

Щоб видалити обліковий запис:

1. Виберіть обліковий запис у списку
2. Натисніть `Del` або виберіть **Обліковий запис → Видалити**
3. Підтвердьте видалення

### Пошук облікових записів

Використовуйте поле швидкого пошуку в головному вікні для фільтрації облікових записів за назвою або постачальником. Пошук працює в реальному часі під час введення.

## Генерація кодів TOTP

### Отримання коду

Щоб отримати код TOTP:

1. Виберіть обліковий запис у списку (клацніть мишею або використайте клавіші стрілок)
2. Натисніть `Enter` або двічі клацніть мишею
3. Відкриється діалогове вікно з TOTP-кодом

### Діалогове вікно TOTP

У діалоговому вікні відображається:

- **Поточний код:** 6-цифровий код, що постійно оновлюється
- **Таймер зворотного відліку:** час до наступного оновлення коду
- **Назва та постачальник:** інформація про обліковий запис

### Копіювання коду

Код автоматично копіюється в буфер обміну при відкритті діалогового вікна. Ви також можете:

- Натиснути кнопку **Копіювати код**
- Використати клавіші `Ctrl+C`

### Автоматичне оновлення

Код автоматично оновлюється згідно з налаштованим інтервалом (зазвичай кожні 30 секунд). При оновленні лунає звуковий сигнал (якщо ввімкнено в налаштуваннях).

## Налаштування

Відкрийте вікно налаштувань через **Опції → Налаштування...** або натисніть `Ctrl+,`

### Вкладка "Поведінка"

| Налаштування | Опис |
|-------------|------|
| Закривати вікно TOTP автоматично | Автоматично закриває діалогове вікно після копіювання коду |
| Відтворювати звук при оновленні коду | Звуковий сигнал при генерації нового коду |
| Відтворювати звук при копіюванні | Звуковий сигнал при копіюванні коду в буфер обміну |
| Приховувати паролі при введенні | Маскує символи пароля зірочками (*) |

### Вкладка "За замовчуванням"

Налаштуйте значення за замовчуванням для нових облікових записів:

| Параметр | Значення | Опис |
|----------|----------|------|
| Кількість цифр | 6 або 8 | Довжина TOTP-коду |
| Алгоритм | SHA1, SHA256, SHA512 | Алгоритм хешування |
| Інтервал | 30 секунд | Час дії коду |

### Зміна мови

Виберіть мову інтерфейсу через **Опції → Мова**. Деякі елементи інтерфейсу застосують нову мову лише після перезапуску програми.

## Гарячі клавіші

### Основні команди

| Клавіша | Дія |
|---------|-----|
| `Ctrl+N` | Створити новий файл |
| `Ctrl+O` | Відкрити файл |
| `Ctrl+,` | Відкрити налаштування |
| `Esc` | Вийти з програми / Закрити діалог |
| `F7` | Додати обліковий запис |
| `Del` | Видалити обліковий запис |
| `Enter` | Відкрити TOTP-код для вибраного облікового запису |

### Навігація

| Клавіша | Дія |
|---------|-----|
| `↑` / `↓` | Переміщення по списку облікових записів |
| `Home` | Перейти до першого облікового запису |
| `End` | Перейти до останнього облікового запису |
| `Tab` | Перехід між елементами |
| `Alt` | Активувати меню |

### Діалогове вікно TOTP

| Клавіша | Дія |
|---------|-----|
| `Ctrl+C` | Копіювати код |
| `Esc` | Закрити вікно |

## Доступність

### Підтримка скрінрідерів

Simple OTP повністю сумісна зі скрінрідерами:

- **NVDA** — рекомендований (безкоштовний, open-source)
- **JAWS** — повна підтримка
- **Windows Narrator** — базова підтримка

### Звукові сповіщення

Програма надає звукові сигнали для важливих подій:

- Оновлення TOTP-коду
- Копіювання коду в буфер обміну
- Помилки валідації

Звукові сигнали можна вимкнути в налаштуваннях (**Опції → Налаштування → Поведінка**).

### Клавіатурна навігація

Всі функції програми доступні через клавіатуру без використання миші. Використовуйте:

- `Tab` для переходу між елементами
- `Enter` або `Пробіл` для активації кнопок
- `Alt` + підкреслена літера для швидкого доступу до меню
- Стрілки для навігації по списках та меню

### Підтримка Braille-дисплеїв

Програма інтегрована з бібліотекою VocaBraille для покращеної підтримки Braille-дисплеїв. Всі текстові елементи коректно відображаються в Брайлі.

### Контрастність та розміри тексту

Simple OTP дотримується системних налаштувань:

- Використовує системні шрифти та розміри
- Підтримує висококонтрастні теми Windows
- Коректно працює з налаштуваннями DPI

## Безпека

### Шифрування даних

Всі файли облікових записів шифруються з використанням:

- **AES-256-GCM** — симетричне шифрування
- **PBKDF2** — деривація ключа з паролю (600,000 ітерацій)
- **Випадкова сіль** — унікальна для кожного файлу
- **Випадковий nonce** — унікальний для кожної операції шифрування

### Рекомендації щодо паролів

Для максимальної безпеки використовуйте паролі, що:

- Містять мінімум 12 символів (чим більше, тим краще)
- Включають великі та малі літери, цифри та спецсимволи
- Не містять словникових слів
- Унікальні для кожного файлу

### Зберігання секретів

> **Важливо:** Секретні ключі Base32 зберігаються в зашифрованому вигляді. Ніколи не діліться вашими файлами облікових записів або секретними ключами з іншими!

### Безпека буфера обміну

Коди TOTP копіюються в системний буфер обміну. Пам'ятайте:

- Інші програми можуть читати вміст буфера обміну
- Очищайте буфер обміну після використання коду
- Не залишайте код в буфері обміну надовго

### Резервне копіювання

Регулярно створюйте резервні копії ваших файлів облікових записів:

1. Копіюйте файли `.json` в безпечне місце
2. Зберігайте резервні копії в зашифрованому вигляді
3. Використовуйте хмарні сховища з двофакторною автентифікацією
4. Зберігайте паролі окремо від файлів (використовуйте менеджер паролів)

## Вирішення проблем

### Невірний пароль

**Проблема:** "Невірний пароль для цього файлу"

**Рішення:**

- Переконайтеся, що ви вводите правильний пароль
- Перевірте розкладку клавіатури (Caps Lock, Num Lock)
- Якщо ви забули пароль, відновити доступ неможливо

### Невірний Base32 секрет

**Проблема:** "Секрет повинен бути правильним рядком Base32"

**Рішення:**

- Base32 містить тільки символи A-Z та 2-7
- Видаліть пробіли та дефіси з секрету
- Переконайтеся, що ви скопіювали секрет повністю
- Деякі сервіси показують секрет у форматі з пробілами — видаліть їх

### Код не співпадає

**Проблема:** Згенерований код не працює на сайті

**Рішення:**

- Перевірте час на вашому комп'ютері — він повинен бути точним
- Синхронізуйте час через налаштування Windows
- Переконайтеся, що параметри (digits, digest, interval) відповідають вимогам сервісу
- Зазвичай використовуються: 6 цифр, SHA1, 30 секунд

### Проблеми зі скрінрідером

**Проблема:** Скрінрідер не читає елементи програми

**Рішення:**

- Переконайтеся, що скрінрідер запущений перед програмою
- Спробуйте перезапустити програму
- Для NVDA: переконайтеся, що увімкнено підтримку UIA (UI Automation)
- Використовуйте клавіатурну навігацію (`Tab`, стрілки)

### Файл не відкривається

**Проблема:** "Не вдалося відкрити файл"

**Рішення:**

- Перевірте, що файл не пошкоджений
- Переконайтеся, що файл не відкритий в іншій програмі
- Перевірте права доступу до файлу
- Спробуйте відновити з резервної копії

### Отримання підтримки

Якщо проблема не вирішується:

- Опишіть проблему детально (що робили, що очікували, що сталося)
- Вкажіть версію програми (див. **Довідка → Про програму**)
- Вкажіть версію Windows та скрінрідера (якщо використовується)
- Створіть issue на GitHub: https://github.com/ruslan-rv-ua/simple-otp
